# testing-theory

Implementing logic coverage testing criteria.

# set up

## Linux

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/clause_coverage.py
```

## Windows

```bat
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
python src\clause_coverage.py
```
